✅ Links Corretti:

  • Homepage → Blog: blog/
  • Blog → Homepage: ../
  • Blog → Articolo: articolo/index.html
  • Articolo → Homepage: ../../
  • Articolo → Blog: ../
  • Articolo → Sezioni: ../../#section
  • Articolo → Altri articoli: ../altro-articolo/

❌ Pattern da Evitare:

  • ./articolo/ - Apre Finder su macOS
  • /blog/ - Path assoluto, non funziona in locale
  • /#features - Path assoluto per anchor
