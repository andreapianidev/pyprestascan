📋 Sezione 1: On-Page SEO (28 Punti)

Meta Tags (10 punti)

  • ☐ Meta title presente su tutte le pagine (prodotti, categorie, CMS)
  • ☐ Meta title unici (no duplicate tra pagine)
  • ☐ Meta title 50-60 caratteri (Google tronca dopo 60)
  • ☐ Keyword principale nel meta title (primi 30 char)
  • ☐ Meta description presente su tutte le pagine
  • ☐ Meta description uniche (no generiche PrestaShop default)
  • ☐ Meta description 150-160 caratteri
  • ☐ CTA nella meta description ("Acquista ora", "Spedizione 24h")
  • ☐ Meta robots corretti (index/noindex, follow/nofollow)
  • ☐ Open Graph tags per social sharing (og:title, og:description, og:image)

Heading Tags (5 punti)

  • ☐ H1 presente e unico su ogni pagina
  • ☐ H1 contiene keyword principale
  • ☐ H2-H6 hierarchy corretta (no H4 prima di H3)
  • ☐ H2 keyword-rich (non "Descrizione", ma "Caratteristiche Nike Air Max 90")
  • ☐ Max 1 H1 per pagina (no multiple H1)

URL Structure (5 punti)

  • ☐ Friendly URL abilitati (no ?id_product=123)
  • ☐ URL descrittivi (/scarpe-running-nike vs /prodotto-123)
  • ☐ URL corti (max 5-6 parole, 60 char)
  • ☐ Lowercase + hyphens (no underscore, no CamelCase)
  • ☐ No parametri inutili (?utm_source ok, ?sessionid=xyz no)

Content Optimization (8 punti)

  • ☐ Product description 300+ parole (long-form rankano meglio)
  • ☐ Descrizioni uniche (no copiate da manufacturer)
  • ☐ Keyword density 1-2% (no keyword stuffing)
  • ☐ LSI keywords (sinonimi e keyword correlate)
  • ☐ Call-to-action chiari ("Aggiungi al carrello", "Compra ora")
  • ☐ Category description 500+ parole (SEO content sopra prodotti)
  • ☐ Bold/italic per keyword (enfasi visuale + SEO signal)
  • ☐ Lists e bullet points (scannerability)

⚙️ Sezione 2: Technical SEO (32 Punti)

Indexing & Crawling (8 punti)

  • ☐ Robots.txt presente e configurato
  • ☐ Robots.txt non blocca risorse (CSS/JS/images)
  • ☐ Sitemap XML presente (/sitemap.xml accessible)
  • ☐ Sitemap XML aggiornato (prodotti nuovi inclusi)
  • ☐ Sitemap submitted a Google Search Console
  • ☐ No pagine orfane (tutte raggiungibili da homepage in 3 click)
  • ☐ Crawl budget ottimizzato (no infinite loop pagination)
  • ☐ Log file analysis (verifica cosa Google crawla realmente)

Canonical & Duplicate Content (6 punti)

  • ☐ Canonical tag presente su tutte le pagine
  • ☐ Canonical self-referencing (ogni pagina canonical a se stessa)
  • ☐ Varianti prodotto con canonical (colori/taglie → canonical a prodotto base)
  • ☐ Pagination canonical (/categoria?p=2 → canonical /categoria o self)
  • ☐ No duplicate content tra lingue (hreflang per multilingua)
  • ☐ Descrizioni prodotto uniche (no duplicate tra varianti)

HTTPS & Security (4 punti)

  • ☐ HTTPS attivo (certificato SSL valido)
  • ☐ Redirect HTTP → HTTPS (301 permanente)
  • ☐ Mixed content risolto (no immagini/CSS via HTTP su pagina HTTPS)
  • ☐ HSTS header (Strict-Transport-Security)

Structured Data (7 punti)

  • ☐ Product schema con price, availability, review (Schema.org Product)
  • ☐ Breadcrumb schema per navigation
  • ☐ Organization schema per brand/company
  • ☐ Review/Rating schema (stelle in SERP)
  • ☐ FAQPage schema su pagine con FAQ
  • ☐ Validato con Google Rich Results Test
  • ☐ No errori structured data in Search Console

Mobile & Responsive (4 punti)

  • ☐ Mobile-responsive design (test su 3+ dispositivi)
  • ☐ Mobile-friendly test Google passed
  • ☐ Viewport meta tag presente
  • ☐ Touch elements distanziati (min 48px tap target)

Redirect & Error Pages (3 punti)

  • (Guida friendly URL e redirect 301)
  • ☐ Zero errori 404 o 301 redirect configurati per broken links
  • ☐ Custom 404 page con link utili (search, categorie popolari)
  • ☐ 301 redirect per URL obsoleti (prodotti discontinued → categoria o simili)

⚡ Sezione 3: Performance SEO (15 Punti)

Core Web Vitals (5 punti)

  • ☐ LCP < 2.5 secondi (Largest Contentful Paint - velocità perceived)
  • ☐ FID < 100 milliseconds (First Input Delay - interattività)
  • ☐ CLS < 0.1 (Cumulative Layout Shift - stabilità visuale)
  • ☐ PageSpeed Score mobile 80+
  • ☐ PageSpeed Score desktop 90+

Loading Speed (6 punti)

(Guida completa performance PrestaShop)

  • ☐ Time to First Byte (TTFB) < 600ms
  • ☐ Full page load < 3 seconds
  • ☐ Browser caching abilitato (Expires/Cache-Control headers)
  • ☐ Server-side caching (Redis, Memcached, o PrestaShop cache)
  • ☐ Gzip/Brotli compression per text resources
  • ☐ CDN per static assets (immagini, CSS, JS)

Image Optimization (4 punti)

  • ☐ Immagini compressed (<200KB per product image)
  • ☐ Lazy loading per immagini below-the-fold
  • ☐ WebP format con fallback JPEG
  • ☐ Width/height attributes su tutte le immagini (evita CLS)

📝 Sezione 4: Content SEO (12 Punti)

Product Pages (5 punti)

  • ☐ Alt text su tutte le immagini prodotto (descrittivo, keyword-rich)
  • ☐ Video prodotto embedded (YouTube/Vimeo) dove applicabile
  • ☐ User reviews visibili (social proof + fresh content per Google)
  • ☐ Related products link interni (internal linking)
  • ☐ Product specs table (dimensioni, peso, materiali...)

Category Pages (3 punti)

  • ☐ Category SEO text sopra o sotto grid prodotti (500+ parole)
  • ☐ Subcategories links (internal linking hierarchy)
  • ☐ Faceted navigation SEO-friendly (filtri non creano duplicate URL)

Blog & Content Marketing (4 punti)

  • ☐ Blog attivo (1-2 articoli/mese minimum)
  • ☐ Articoli 1.500+ parole (long-form content)
  • ☐ Internal links da blog a prodotti (conversion funnel)
  • ☐ Content calendar pianificato (keyword research driven)
